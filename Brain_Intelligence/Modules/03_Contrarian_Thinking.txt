# MODULE 3: CONTRARIAN THINKING

## THE ART OF OPPOSITE

When everyone is buying - we sell.
When everyone is selling - we buy.

---

## CONTRARIAN PRINCIPLES

### 1. Crowd is Wrong at Extremes

```
Extreme Greed → TOP is near
Extreme Fear → BOTTOM is near
```

### 2. Consensus is Usually Wrong

```
When 90% bullish → Only 10% can be buyers
When 90% bearish → Only 10% can be sellers
```

### 3. Follow the Smart Money

```
Smart Money = Institutions = Opposite of retail
When retail buys → institutions sell
When retail sells → institutions buy
```

---

## CONTRARIAN SIGNALS

### Extreme Greed Indicators:

- Everyone talking about one stock
- Record IPO activity
- Margin debt at highs
- Put/Call ratio at lows
- High VIX fear = low fear actually

### Extreme Fear Indicators:

- No one wants to talk about stocks
- Record low IPOs
- Margin debt being forced liquidation
- Put/Call ratio at highs
- VIX at extremes

---

## OUR CONTRARIAN RULES

### When To Be Contrarian:

1. **Market Euphoria**
   - Everyone is bullish
   - Record highs
   - FOMO everywhere
   → START SELLING

2. **Market Panic**
   - Everyone is bearish
   - Record lows
   - Despair everywhere
   → START BUYING

### Position Sizing:

```
More contrarian = Larger position
But: Can be wrong for months
Size appropriately!
```

---

## CONTRARIAN SUCCESS FACTORS

1. **Conviction** - Believe when others doubt
2. **Patience** - May take months
3. **Position sizing** - Don't go all-in
4. **Timing** - Average in/out
5. **Risk management** - Know when wrong
