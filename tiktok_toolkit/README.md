## Installation & Setup Guide

### Prerequisites
1. Node.js installed
2. TikTok account (for content posting)
3. OBS Studio (for multi-platform streaming)

## 🎯 QUICK START

### 1. Run the Toolkit
```bash
cd ~/Desktop/Stock_Analysis/tiktok_toolkit
node scheduler.js
```

### 2. Schedule Posts
Edit `config.json` to set your:
- TikTok session cookie
- Posting times
- Content themes

### 3. Start Streaming
```bash
# Use OBS for TikTok LIVE
# Toolkit runs in background
```
