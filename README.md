## 🚀 Getting Started

### Prerequisites
- macOS (Apple Silicon supported)
- Node.js 18+
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/eblq77-web/stock-analysis.git
cd stock-analysis

# Install dependencies (if any)
npm install
```

### Running SuperBrain Pro

```bash
# Full comprehensive scan
node comprehensive_scanner.js

# Quick market scan
node mega_scanner.js

# Institutional analysis
node institutional_scanner.js

# Quantum pattern analysis
node quantum_super_brain.js

# Self-learning update
node self_learning_engine.js
```

### Dashboard

Open in browser:
```bash
open SUPER_BRAIN_PRO_V4.html
```
